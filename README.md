## ⭐ Projeto destaque — Metha Facial

> **Plataforma SaaS de Análise de Microexpressões para Clínicas de Saúde Mental**

Psicólogos e terapeutas perdem sinais emocionais sutis que o olho humano não capta em tempo real.
A **Metha Facial** transforma esses sinais invisíveis em dados clínicos acionáveis — 100% no navegador,
sem câmeras externas, sem instalar nada.
